# Security Policy

## Reporting Security Vulnerabilities

We take the security of Excalibur seriously. If you believe you have found a security vulnerability in Excalibur itself (such as memory corruption, arbitrary code execution outside the sandbox, or unintended privilege escalation), please do **NOT** open a public issue.

Instead, please report security vulnerabilities responsibly:

1. **Email**: Send details to [bhargavnarumanchi779@gmail.com](mailto:bhargavnarumanchi779@gmail.com)
2. **Details to Include**:
   - Step-by-step reproduction instructions or a minimal Proof of Concept (PoC).
   - The affected component (`excalibur-core`, `excalibur-proxy`, `excalibur-dom`, `excalibur-script`, etc.).
   - Operating system and version of Excalibur.
   - Any proposed fix or mitigation.

We will acknowledge your report within 48 hours and work with you on a coordinated disclosure timeline.
